Two manuals live here:

- **ck-git-hosting** — A lightweight, zero-database Git control plane over OpenSSH for Linux servers and Raspberry Pi: multi-device checkout synchronization (`ckgit`), a hardened zero-JS web dashboard (`ck-git-hostingd`), pull-based native CI/CD across Linux, Windows, and macOS (`ck-ci-runnerd`), release archives, and Pages hosting (`ck-pagesd`).
- **ckdocs** — A single-binary C++20 documentation generator that turns repository Markdown, GFM alerts, 73 syntax-highlighted languages, TeX math, and 23 Mermaid/XY diagram types into a fast, searchable static website with no Node.js or Python dependencies.
